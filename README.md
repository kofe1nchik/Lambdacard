# λ Lambdacard

**Lambdacard** — это современное браузерное расширение для изучения иностранных слов с использованием интервальных повторений (SRS).

В отличие от простых "карточек", Lambdacard использует **FSRS (Free Spaced Repetition Scheduler)** — продвинутый нейросетевой алгоритм (как в современном Anki), который подстраивается под вашу память.

![Logo](public/logo.png)

## ✨ Возможности

*   🧠 **Умный алгоритм FSRS:** Рассчитывает идеальное время для повторения каждой карточки.
*   🌐 **Контекстное меню:** Добавление слов прямо со страницы браузера (выделите текст -> ПКМ -> Добавить).
*   🗣️ **Автоперевод:** Мгновенный перевод слов через Google Translate при создании карточек.
*   📊 **Настройка:** Возможность оптимизировать веса алгоритма через анализ истории (экспорт в Python/Colab).
*   💾 **Бэкапы:** Полный экспорт и импорт базы данных в JSON.
*   🎨 **UI/UX:** Стремление к Material Design, темная тема, плавные анимации.

## 🛠 Технический стек

*   **Core:** Vanilla JavaScript (ES Modules)
*   **Build Tool:** Vite + CRXJS Plugin
*   **Database:** IndexedDB (Native)
*   **Algorithm:** `ts-fsrs` library
*   **Manifest:** V3

## 🚀 Как собрать проект (Build)

Для сборки вам понадобится установленный [Node.js](https://nodejs.org/) (версия 16+).

### 1. Клонирование и установка зависимостей

Откройте терминал и последовательно выполните команды:

```bash
# Клонировать репозиторий (Или просто скачайте и распакуйте архив)
git clone https://github.com/kofe1nchik/Lambdacard.git

# Перейти в папку (Путь может меняться в зависимости от расположения файла)
cd lambdacard

# Установить зависимости
npm install
```

### 2. Сборка (Production)

Чтобы создать готовую версию расширения:

```bash
npm run build
```

После этого в корне проекта появится папка **`dist`**. Именно её нужно загружать в браузер (см. раздел _Как установить в Chrome / Edge_).

### 3. Упаковка в ZIP (Опционально)

Если вам нужен готовый архив для Web Store или передачи другу:

```bash
npm run zip
```
Файл `lambdacards.zip` появится в корне проекта.

## 🔧 Запуск в режиме разработки (Dev Mode)

Если вы хотите вносить изменения в код и сразу видеть результат:

1.  Запустите команду:
    ```bash
    npm run dev
    ```
2.  Загрузите папку `dist` в браузер (см. инструкцию ниже).
3.  При изменении кода расширение будет обновляться автоматически (HMR).

---

## 📥 Как установить в Chrome / Edge

1.  Перейдите по адресу `chrome://extensions/`.
2.  Включите **"Режим разработчика"** (Developer mode) в правом верхнем углу.
3.  Нажмите кнопку **"Загрузить распакованное"** (предварительно распаковав расширение).
4.  Выберите папку **`dist`**, которая появилась после сборки. (или просто распакованное расширение, если скачивали релиз)

## 🤖 Оптимизация алгоритма

В расширении встроен механизм сбора истории обучения.
1.  Накопите статистику (минимум 100 повторений).
2.  В настройках нажмите **"Инструкция и Оптимизация"**.
3.  Скачайте историю и используйте Google Colab скрипт для расчета ваших персональных параметров памяти.
